Ingress Origin Whitelisting – PSG

Self-service portal to whitelist application domains for secure communication with the Platform Security Gateway (PSG). All changes are applied dynamically at runtime.

Step 1: Application Identification

CSI uniquely identifies your application in PSG. If your CSI is not listed, select Register New CSI and enter a new one.

Step 2: PSG Instance Selection

Select the PSG instance(s) where your application is onboarded. (Multiple selection allowed)
What is an Application Origin?
An origin is the application domain or hostname from which API requests are sent to PSG. PSG will allow requests only from the domains listed below.

Examples:
• https://dev.myapp.company.com
• https://uat.myapp.company.com
• https://www.myapp.com

Step 3: Non-Production Application Domains (Calling PSG)

🧪 Applies to DEV UAT PERF environments.
Each non-production domain requires one-time approval by the CSI Manager before PSG access is enabled.

Step 4: Production Application Domains (Calling PSG)

⚠️ Production access is tightly controlled.
Add only live application domains that will call PSG. A valid Change Request (CR) is mandatory and will be validated automatically.
This CR will be validated and applied to all production domains. The CR must be in Active / Implementation stage and linked to the selected CSI.
