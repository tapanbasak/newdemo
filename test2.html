Ingress Origin Whitelisting – PSG

Self-service portal to whitelist application domains for secure communication with the Platform Security Gateway (PSG). All changes are applied dynamically at runtime.

Overview
Use this form to register application domains that are allowed to call PSG. Typical completion time is under 5 minutes.

You will need:
  • CSI (Client Service Identifier)
  • Application domains for Non-Production and/or Production
  • A valid Change Request (CR) if requesting Production access

Step 1: Choose environment scope

Non-Production only
  • DEV / UAT / PERF environments
  • One-time approval by CSI Manager
  • Safe for testing and validation
Production
  • Live customer traffic
  • Requires a valid Change Request (CR)
  • Stronger governance and approvals

Step 2: Identify your application (CSI)

CSI uniquely identifies your application in PSG. If your CSI is not listed, select Register New CSI and enter a new one.

Step 3: Choose PSG instances

Select the PSG instance(s) where your application is onboarded. Multiple selection is allowed.
Application origins are the domains or hostnames from which your application will call PSG.

PSG will only accept requests from the origins you list below.

Examples:
• https://dev.myapp.company.com
• https://uat.myapp.company.com
• https://www.myapp.com

Step 4: Non-Production Application Domains (Calling PSG)

Applies to DEV UAT PERF environments.
Each non-production domain is sent to your CSI Manager for one-time approval before it can call PSG.
Enter full HTTPS URLs for your DEV, UAT, or PERF frontends that will call PSG.

Step 5: Production Application Domains (Calling PSG)

⚠️ Production access is tightly controlled.
Add only live customer domains that will call PSG. A valid Change Request (CR) for this CSI is required and will be validated automatically.
Enter full HTTPS URLs for customer-facing domains that will send live traffic to PSG.
This CR will apply to all production domains listed here. It must be in Active / Implementation stage and linked to the selected CSI.
